## 方法（核心机制）

### 1. Scaled Dot-Product Attention（§3.2.1，全文的心脏）

$\text{Attention}(Q,K,V) = \text{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)V$

逐块拆解（自己写）：

- $QK^\top$ 的第 $(i,j)$ 元是什么？（提示：内积 / Gram 矩阵）
- 除以 $\sqrt{d_k}$ 为什么必要？（提示：设 q,k 各分量 iid 均值 0 方差 1，算 $q\cdot k$ 的方差）
- softmax 逐行作用后，每一行是什么？（提示：一个分布）
- 最后乘 V 得到的输出，是 V 的什么？（提示：凸组合 → 输出落在 conv(V) 里）

**我的推导笔记**（先直觉，后严格化）：

**1.** **$QK^\top$：query 与 key 的相似度矩阵（Gram 矩阵）**

直觉（我原来的理解）：度量一个词和另一个词之间「查找 / 被查找」的联系程度——A 要查找 B 的程度有多大。

精确表述：每个位置 $i$ 带三个向量 $q_i, k_i, v_i \in \mathbb{R}^{d_k}$（都由该位置的词向量经线性投影得到）。$QK^\top$ 的第 $(i,j)$ 元 = $q_i \cdot k_j$：**位置** **$i$** **作为查询者，与位置** **$j$** **作为被查者的内积相似度**。整个矩阵是一个数据依赖的双线性型（Gram 矩阵），一次矩阵乘算出所有位置对的两两相似度，所以可完全并行。

**2. 除以** **$\sqrt{d_k}$：把点积的方差归一化，防止 softmax 饱和（严格推导）**

我原来的直觉：不除 $\sqrt{d_k}$，点积方差可能非常大，联系程度差距过大，softmax 算出非常小（极端）的结果。补成完整论证：

- 设 $q, k$ 各分量 iid、均值 $0$、方差 $1$，则

$\mathrm{Var}(q\cdot k)=\mathrm{Var}\!\Big(\sum_{i=1}^{d_k}q_i k_i\Big)=\sum_{i=1}^{d_k}\mathrm{Var}(q_i)\mathrm{Var}(k_i)=d_k.$

即点积的标准差是 $\sqrt{d_k}$。Transformer 中 $d_k=64$，标准差 $\approx 8$，分数到 ±10、±20 是常态。

- softmax $p_i=e^{x_i}/\sum_j e^{x_j}$ 对大输入极敏感：
  | 输入                 | softmax 输出                             |
  | ------------------ | -------------------------------------- |
  | $(2.5, 2.0, 1.25)$ | $(0.52, 0.32, 0.15)$ ← 健康的软性分布         |
  | $(20, 16, 10)$     | $(0.982, 0.018, 0.00004)$ ← 几乎 one-hot |
- 饱和后梯度消失：softmax 的 Jacobian 对角元是 $p_i(1-p_i)$，$p\to 1$ 或 $p\to 0$ 时都趋零（$0.982\times0.018=0.018$，$4\times10^{-5}$）。与 tanh 饱和（$1-o^2\to 0$）是同一机制——学习信号传不回去。
- 除以 $\sqrt{d_k}$ 后分数方差由 $d_k$ 归回 $1$，典型幅度 ±1\~3，softmax 停在「既非均匀、又非 one-hot」的敏感区，处处有梯度。

**因果链一句话**：维度高 → 点积方差 $=d_k$ 偏大 → softmax 饱和成 one-hot → $p(1-p)\approx 0$ 梯度消失 → 除 $\sqrt{d_k}$ 把方差归一回 1。

**3. softmax 逐行作用：每行是一个概率分布（注意力权重）**

$QK^\top/\sqrt{d_k}$ 的每一行（对应一个 query）过 softmax 后，变成非负、和为 1 的权重向量——这是一次「软性查找」：不像哈希/dict 硬选一个 key，而是按相似度给所有位置分配权重。

**4. 乘** **$V$：输出是 value 向量的凸组合**

$\text{softmax}(\cdots)V$ 的第 $i$ 行 = $\sum_j p_{ij} v_j$。权重非负且和为 1，所以输出落在 $\mathrm{conv}\{v_1,\dots,v_n\}$ 里——即「由前面权重加权出的综合表示」（我原来写的「综合的匹配程度」方向对，更准确说是 **value 的加权重心，而非相似度本身**）。相似度决定权重，权重去混合内容 $V$——查的是 $K$，取回的是 $V$。

**辨析（延伸讨论）**：

**A. 饱和时「不知道往哪优化」更准确的说法：路由被锁死**

梯度趋零不是方向错，而是幅度趋零：softmax 对所有 logit 的偏导都接近 0，下游 loss 传回来的信号几乎改变不了任何权重——即使当前「全押一个」的分配是错的，也推不动它。但有个精细区别：饱和杀死的只是**改权重的能力**。输出 $o=\sum_j p_j v_j$ 对 $v_j$ 的梯度恰为 $p_j$——被选中的 value 仍以梯度 ≈1 学习，其余 value 梯度 ≈0。即模型还能「把选中的内容学好」，却学不会「该去看别人」。proof agent 视角：模型一旦锁死某条错误证明分支，很难自己跳出。

**B. 「凸」的几何含义：只能插值，不能外推**

$p_j\ge 0$、$\sum_j p_j=1$ 意味着权重向量在单纯形 $\Delta^{n-1}$（凸集）上，输出的值域恰为 value 的凸包。一维例：$v_1=1, v_2=3$，凸组合只能落在 $[1,3]$（插值）；允许负系数（一般线性组合）则可外推：$2v_2-v_1=5$，$2v_1-v_2=-1$。向量情形：三个 value 张成三角形，凸组合永远在三角形内部——无法表达「反向拉扯」「放大差异」。这是 softmax-attention 的表达力限制，linear-attention 去掉归一化后即突破。

**C. 「遍历凸包」是值域意义，不是单次调用**

一次前向：分数确定 → softmax 给出**一组**确定权重（单纯形上一个点）→ 输出是凸包里**一个点**。「遍历」说的是固定 $V$、让分数任意变化时的**值域**：对单纯形内部任意目标权重 $p$，取分数 $x_j=\log p_j$ 即可由 softmax 精确得到（softmax 与 log 在此意义上互逆），故

$\Big\{\textstyle\sum_j p_j v_j : p\in\Delta\Big\}=\mathrm{conv}\{v_1,\dots,v_n\}.$

类比：$f(x)=x^2$ 每次只输出一个非负数，但其值域是 $[0,\infty)$。推论：**$V$** **决定输出能落在哪个区域（凸包），$Q,K$** **只决定在该区域内落到哪个点**——学 $V$ 与学 $Q,K$ 是两种不同能力。另：softmax 有平移不变性（所有分数同加常数输出不变），只关心相对差距。

**D. softmax 不是唯一的权重函数**

| 替代                                   | 做法                                        | 动机                   |
| ------------------------------------ | ----------------------------------------- | -------------------- |
| sparsemax (2016)                     | 分数欧氏投影到单纯形                                | 权重出现精确 0，真正稀疏        |
| entmax (2019)                        | softmax–sparsemax 之间的一族                   | 可调稀疏度                |
| linear/kernel attention（Performer 等） | 以 $\phi(q)^\top\phi(k)$ 替代 $e^{q\cdot k}$ | 去 softmax，O(n²)→O(n) |
| sigmoid 门控                           | 各位置独立开关、不归一化                              | 允许「都不选」              |
| Gumbel-Softmax                       | 训练可微、推理离散                                 | 硬路由也要可训练             |

softmax 统治实践的理由：给定分数下的**最大熵分布**（Boltzmann），处处光滑、一个 exp 可算、缩放后 Jacobian 行为良好。注意 Bahdanau 加性注意力换的是打分函数（小 MLP），归一化器仍是 softmax。

### 2. Multi-Head（§3.2.2）

- 为什么要先线性投影到 h 个 d\_k 维子空间再各自 attention，而不是直接做一次大 attention？

**我的理解**：

**一句话总结**：单头 attention 的一组权重做一次加权平均——不同类型的关系被迫妥协成一个折中结果，谁都没被充分捕捉（"averaging inhibits this"）。多头用 h 组独立权重各自专注一种关系，拼接后全部保留，由 $W^O$ 学习如何混合——**用并行做多次平均再拼接来避免信息损失**。

**（a）投影矩阵做了两件嵌套的事**

第一层：Q/K/V **角色区分**。同一个词 $x\in\mathbb{R}^{d_{model}}$ 被三组矩阵 $W^Q, W^K, W^V$ 投影成三个不同向量，分别扮演查询者、被查者、内容载体。没有投影的话 $x\cdot x$ 总是正数、没信息量，三种角色混在一起没法学。**这层是单头 attention 也需要的**。

第二层：头间**关系类型区分**。同一个词"在找什么"本身是多种维度的：头 1 的 $W_1^Q$ 可能让 query 沿"名词找动词"的方向投影，头 2 沿"代词找先行词"的方向投影，头 3 沿"相邻位置强相关"的方向投影。不同头有不同的 $W_i^Q, W_i^K, W_i^V$，所以即使角色已分开，不同头看到的仍是同一种角色的不同切面。论文说"averaging inhibits this"——不是 Q/K/V 被平均了，而是**多种关系类型被一组权重平均了**。

**（b）投影不是"调维数"，是学习到的线性变换**

$W_i^Q \in \mathbb{R}^{512\times 64}$ 把 512 维映射到 64 维。它是**可学习的**（训练时用梯度下降更新），所以不是固定几何投影，而是数据驱动的满秩线性变换——可以旋转、缩放、非正交地斜切进子空间。每个头有自己的三个矩阵，所以每个头看到的"同一个词"投影后的表示不一样。

**（c）$d_{model}$** **是模型内部表示的环境维度**

$d_{model}=512$：序列里每个 token 在整个网络中都被表示为 $\mathbb{R}^{512}$ 里的一个向量。所有词向量、中间表示、层间传递都是 512 维向量。这个数字是模型的"带宽"——越大表达力越强但算力开销也越大。

**（d）512 维不是 512 个独立特征**

512 维向量 = 512 个实数分量，但不要理解为"512 个离散可命名的特征"。这些分量是分布式编码：一个语义特征通常分散在多个维度上，一个维度也通常同时参与编码多个特征。有意义的不是单个分量的大小，而是向量在某个学习到的**方向**（多分量线性组合）上的投影。512 越大 → 空间能容纳更多独立方向 → 能编码更多更细的特征。

**（e）Q/K/V 各自的含义**

同一个输入 $x$ 被三组矩阵投影成三个角色：Query = "我在找什么"（拿着检索词去查），Key = "我能提供什么"（书架上的标签），Value = "我实际携带的内容"（书的内容本身）。$q$ 和 $k$ 只参与算权重，算完就丢；**真正流到下一层的是** **$v$** **的凸组合**。

**（f）多头不是 64 个分类器，是一个 64 维子空间里的线性映射**

头 1 的 64 维 query 和 64 维 key 做点积 → 一个标量分数 → softmax 变成权重。**分类/选择是整体完成的，不是逐维完成的**。打分 $q\cdot k$ 是 $\mathbb{R}^{64}$ 上的线性泛函 $\langle q, k\rangle$——对偶空间里的元素对一个向量求值。不同的头 = 不同的 64 维子空间 = 不同的打分标准。

**（g）层间数据流：上一层输出 = 下一层输入**

每一层的 attention 输出 $o = \sum_j p_j v_j$ 是 value 的加权混合（融合了上下文信息的新表示），加上残差连接后作为下一层的输入。下一层用自己的投影矩阵再把它分解成新的 Q/K/V。越往后每个位置的表示越"见过世面"——层 1 的"猫"只知道自己是个词，层 12 的"猫"已融合了整句话的语义。

**（h）计算量为什么不增**

单头：$O(n^2 d_{model})$。多头：$h \cdot O(n^2 d_{model}/h) = O(n^2 d_{model})$。额外成本只是 $h+1$ 个投影矩阵（$O(n d_{model}^2)$）。表达力近乎免费地增加——这是工程上极漂亮的一步。

### 3. 位置信息（§3.1 + §3.5）

- 没有 RNN，模型怎么知道词序？sin/cos 位置编码不同频率像什么？

**我的理解**：在编码器和解码器栈最底层的输入嵌入（input embedding）上加上"位置编码"。低频高频对应所谓"波长"（反比关系），高频相应的"波长短"，短时间内收集到的信息就相对较少，处理的是短信息（局部顺序，"这个词旁边是谁"）；低频反之，处理的是长距离信息（全局位置，"这个词在句子大约什么位置"）。如同局部坐标卡和全局坐标卡——高频项像局部坐标卡（只在邻近点有效），低频项像全局坐标（覆盖整个流形），两者叠加才能同时表达"近"和"远"。

**补充**：attention 本身是置换等变的（permutation equivariant）——打乱输入顺序，输出行跟着同步打乱但每行的值不变，所以位置对应关系始终保留（输入第 $i$ 个位置 → 输出第 $i$ 行）。但"哪个内容在第 $i$ 个位置"这个顺序信息丢失了，所以需要位置编码从外部注入。

sin/cos 位置编码的核心数学性质：对任意固定偏移 $k$，$PE_{pos+k}$ 是 $PE_{pos}$ 的线性函数（旋转矩阵 $R(\omega k)$）。这意味着 attention 里的线性操作（$QK^\top$）天然能捕捉相对位置——$k$ 不是需要学习的参数，模型通过学习投影矩阵 $W^Q, W^K$ 间接选择"关注哪些相对距离"。
