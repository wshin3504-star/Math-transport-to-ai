## Set 1：函数、循环、列表（题 1–4）

### 第 1 题　埃氏筛法　★
- **知识点**：函数、list、布尔列表、for/range、嵌套循环
- **题面**：`sieve(n)` 返回所有不超过 n 的素数，从小到大排列。
- **约定**：`sieve(1)` 返回 `[]`；`sieve(2)` 返回 `[2]`。
- **提示**：开一个长度 n+1 的 `is_prime = [True]*(n+1)`，从 i=2 开始，把每个素数的倍数
  （从 `i*i` 起步即可）标成 False。最后收集仍为 True 的下标。

### 第 2 题　牛顿法求平方根　★
- **知识点**：while 循环、浮点数、误差控制、边界处理
- **题面**：`newton_sqrt(a, tol=1e-12)` 用迭代 x ← (x + a/x)/2 求 √a，
  初始 x₀ = a/2，当 |x²−a| ≤ tol 时停止并返回 x。
- **约定**：a = 0 直接返回 0.0（否则会除以 0）。
- **提示**：你学分析，收敛性不用我讲；注意工程上先处理退化输入。

### 第 3 题　最长考拉兹链　★★
- **知识点**：函数拆分、while、整数运算、打擂台（argmax 模式）
- **题面**：考拉兹映射 n → n/2（偶）、3n+1（奇），任何正整数最终到 1。
  `collatz_longest(limit)` 在起点 1 ≤ s ≤ limit 中，找链长（含起点和 1）最大的，
  返回 `(起点, 链长)`；并列取起点较小者。
- **自检**：`collatz_longest(10) == (9, 20)`。
- **提示**：写一个 `chain_len(n)` 子函数；并列处理靠「只在严格更长时更新」。

### 第 4 题　欧拉函数　★
- **知识点**：自己实现 gcd（欧几里得算法）、计数、取模
- **题面**：`euler_phi(n)` 统计 1 ≤ k ≤ n 中与 n 互素的数的个数。
  约定 φ(1) = 1。
- **自检**：φ(9)=6，φ(10)=4，φ(12)=4。
- **提示**：`gcd(a,b)` 用「while b: a,b = b,a%b」四行写完；
  `a,b = b,a%b` 这种**多元赋值**是 Python 常用写法。

## Set 2：字典、字符串、嵌套结构（题 5–8）

### 第 5 题　词频统计　★
- **知识点**：str 方法（lower/split/strip）、dict 计数、sorted 排序键
- **题面**：`word_frequency(text)` 把文本转小写、按空白分词、去掉词尾标点
  （只处理 `.,;:!?"'()` 这些），返回 `[(词, 次数), ...]`，
  先按次数降序，次数相同按词条字典序升序。
- **提示**：`sorted(items, key=lambda t: (-t[1], t[0]))` 一次搞定两个排序准则；
  `lambda t: ...` 是匿名函数，先照抄会用就行。

### 第 6 题　矩阵乘法　★★
- **知识点**：嵌套列表、三重循环、下标
- **题面**：`mat_mul(A, B)` 纯 Python 实现矩阵乘法（**禁止 numpy、禁止 zip 取巧**，
  这题就是要让你把下标循环写熟）。输入保证维度合法。
- **自检**：[[1,2],[3,4]] × [[5,6],[7,8]] = [[19,22],[43,50]]。
- **提示**：结果先初始化成全 0 的 m×p 列表：`[[0]*p for _ in range(m)]`
  （注意不能写 `[[0]*p]*m`，想想为什么——踩坑也是学习）。

### 第 7 题　合并区间　★★
- **知识点**：tuple/list、sort、遍历时维护状态
- **题面**：`merge_intervals(intervals)` 输入若干 `[起点, 终点]`，
  把所有重叠或端点相接的区间合并，返回排序后的 tuple 列表。
- **自检**：`[[1,3],[2,6],[8,10],[15,18]]` → `[(1,6),(8,10),(15,18)]`；
  `[[1,3],[3,5]]` → `[(1,5)]`（相接也合并）。
- **提示**：先按起点排序；维护 `cur`，新区间起点 ≤ cur 终点就扩展，否则结算。

### 第 8 题　稀疏向量点积　★★
- **知识点**：dict 遍历、算法意识（选更小的表遍历）
- **题面**：向量用 dict 表示「下标: 分量」，0 分量不存。
  `sparse_dot(x, y)` 用 O(较小向量非零元个数) 求点积。
- **自检**：`{0:2, 2:3}` · `{0:4, 1:5, 2:1}` = 11。
- **提示**：`if k in y` 判断键是否存在；可以先比较 `len(x), len(y)` 决定遍历谁。

## Set 3：递归、推导式、闭包与高阶函数（题 9–12）

### 第 9 题　快速排序（函数式写法）　★★
- **知识点**：递归、列表推导式 `[... for ... if ...]`、不可变风格
- **题面**：`quicksort(lst)` 返回新列表（**不修改原列表**）：取首元素为 pivot，
  其余元素中 ≤ pivot 的放左、> pivot 的放右，递归拼接。
- **自检**：空表、已排序、含重复元素都要对；用随机列表与内置 `sorted()` 对比。
- **提示**：主体可以只有一行 return，但建议先分三行写清楚。

### 第 10 题　memoize 缓存装饰器　★★★
- **知识点**：函数作参数、闭包、`*args` 可变参数、dict 做缓存
- **题面**：`memoize(f)` 返回一个新函数：同样的参数第二次调用时直接返回缓存结果，
  不再执行 f。判题器会用它装饰递归 fibonacci 并验证「每个 n 只被真正计算一次」。
- **提示**：缓存键直接用 `args`（tuple 可哈希）；骨架大致是
  `cache = {}` → `def wrapper(*args): ...` → `return wrapper`。
  这题的闭包结构和 micrograd 里 `_backward` 闭包是同一个套路，务必吃透。

### 第 11 题　中心差商求导（返回函数的函数）　★★
- **知识点**：高阶函数、闭包、函数作为返回值
- **题面**：`derivative(f, h=1e-6)` 返回函数 g(x) ≈ [f(x+h)−f(x−h)] / (2h)。
- **自检**：x² 在 3 处 ≈ 6；sin 在 0 处 ≈ 1。
- **提示**：`return lambda x: ...` 或在内部 `def g(x)` 再 return g，二选一。

### 第 12 题　数值梯度　★★★
- **知识点**：列表复制与逐坐标扰动、推导式；直接对应 micrograd 第 4 节自检
- **题面**：f 接受一个 list（向量）返回标量。`numerical_gradient(f, x, h=1e-6)`
  对每个坐标 i 用中心差商求偏导，返回梯度列表。
- **自检**：f(x)=Σx 的梯度全为 1；f(x)=x₀²+2x₁² 在 (3,4) 处为 [6, 16]。
- **提示**：扰动第 i 维时用 `xp = x.copy(); xp[i] += h`，别改了原向量。
  **这题的代码将来直接用来检验你手写的反向传播**，认真写。

## Set 4：面向对象与运算符重载（题 13–16）

### 第 13 题　Fraction 有理数类　★★
- **知识点**：`class`、`__init__`、`self`、双下划线运算符、`__repr__`、`__eq__`
- **题面**：实现不可约分数（分母恒为正）：
  - `Fraction(a, b)` 构造时用 gcd 约分；
  - 支持 `+`（通分后仍要约分）、`==`；
  - `repr` 形如 `"1/2"`。
- **自检**：Fraction(1,2)+Fraction(1,3) == Fraction(5,6)；
  Fraction(2,4) == Fraction(1,2)；Fraction(1,-2) 归一化后分子为 −1。
- **提示**：这就是 micrograd 里 `__add__` 机制的预演——`a+b` 会调用 `a.__add__(b)`。

### 第 14 题　Polynomial 多项式类　★★
- **知识点**：列表即数据、属性封装、`__call__`
- **题面**：系数按低次到高次存，如 `[1,2,3]` = 1+2x+3x²。实现：
  - `p(x)`：Horner 法求值（一次循环，无幂运算）；
  - `+`：逐系数相加，长度不等时补 0；
  - `degree`：次数属性（零多项式约定为 −1）。
- **自检**：Polynomial([1,2,3])(2) == 17。
- **提示**：Horner：1+2x+3x² = 1 + x(2 + 3x)，从高到低累乘。

### 第 15 题　Linear 线性层雏形　★★
- **知识点**：组合、对象持有参数、与矩阵题呼应
- **题面**：`Linear(W, b)` 保存权重（nout×nin 的嵌套列表）和偏置；
  `layer(x)` 返回 Wx+b；`parameters()` 把所有权重和偏置摊平成一个 list 返回。
- **自检**：W=[[1,2],[3,4]], b=[1,1], x=[1,1] → [4,8]；
  parameters() == [1,2,3,4,1,1]。
- **提示**：`__call__` 让对象能像函数一样被调用——micrograd 的 Neuron 就是这么写的。

### 第 16 题　Number 标量自动微分（选做，★★★）
- **知识点**：本题 = micrograd 第 1–3 节的闭卷默写版
- **题面**：实现带计算图的标量 Number：
  - 记录 data、grad、孩子节点集合；
  - `+`、`*` 在构造结果节点的同时，用闭包记录「梯度如何回传」的规则；
  - `backward()` 从自身（grad=1）出发，拓扑排序逆序执行所有回传规则。
- **自检**：L = (a·b + c)·f，a=2,b=−3,c=10,f=−2 时，
  da=6, db=−4, dc=−2, df=4。
- **建议时机**：先跟视频做完 micrograd 的 SECTION 1–3，过两天再回来看这题，
  **不看任何资料独立默写**——能默出来，说明这部分真的会了。
